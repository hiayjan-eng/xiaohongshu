# M0 真实全量扫描用户指南

## 验收前确认

1. 在扩展管理页加载交付目录 `release-artifacts/extension-m0-full-scan-preview`。
2. 确认扩展显示 `0.3.0-m0-preview`，Side Panel 顶部显示 `M0 全量扫描 Preview 0.3.0`。
3. 确认导入目标是交付的 M0 Preview URL，不是 Production。
4. 打开小红书“我 → 收藏 → 笔记”，再打开扩展 Side Panel。

## 一键全量扫描

点击“扫描全部收藏”后不要手动滚动。系统会自动滚动并流式保存。验收过程中请关闭 Side Panel 再打开一次，并刷新小红书页面一次；同一账号、同一收藏页会恢复原 ScanSession。

如果出现验证码、风控、登录失效或网络错误，系统会安全暂停。请在小红书页面手动处理，然后点击“继续”。不要重新开始，除非你明确要放弃旧进度。

## 复核

扫描完成后：

1. 记录总发现数、有效收藏、无链接和待检查。
2. 点击“随机 50 条”，检查没有本人发布内容和明显重复。
3. 随机打开 20 条原帖；至少 19 条应打开正确笔记，删除或不可见笔记不算错误跳转。
4. 可展开“脱敏诊断”并导出统计文件；文件不含收藏正文或账号 ID。

## 导入与撤销

点击“导入收藏复活”。浏览器会打开精确 M0 Preview，并显示本次将导入、新增、已存在和待检查数量。核对后点击“确认导入”。刷新 Preview，数量应保持。

如需回退，点击“撤销本次导入”。它只删除当前 importBatchId 新增的记录，不影响其他批次。第二次扫描同一收藏库时，新增应为 0，除非小红书收藏库确实新增了笔记。

完成真实 3000+ 收藏验收前，不要 merge main、不要打 tag、不要 Promote 或部署 Production。
