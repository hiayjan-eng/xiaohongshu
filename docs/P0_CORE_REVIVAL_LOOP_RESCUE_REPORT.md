## 验证记录

1. **打开收藏页**：扩展不再写死 `/user/profile`，按钮只打开 `https://www.xiaohongshu.com/`，并明确提示用户自行进入「我」→「收藏」。未模拟登录或绕过限制。
2. **当前收藏页识别**：识别同时要求小红书个人主页、已加载可见笔记卡、`tab=fav` 或激活的「收藏」标签；selector 版本为 `xhs-fav-visible-cards-v3`。
3. **10—20 条扫描**：popup 和扫描器均强制限制为 10 或 20 条。扩展 DOM 验证使用真实结构形态的 mock 页面，识别到 2 条可见收藏，结果大于 0。
4. **导入与重复**：`import-center.spec.ts` 覆盖扩展 payload 导入、批次记录和专辑候选；通过。
5. **8 条验收语义集分类**：新增 E2E 覆盖竞品流量、关系、生日晚餐、孤独、外贸、AI 剪辑、Codex + Chatcut、Codex 提示词。至少形成 4 个一级主题；关系和餐厅均未归入「小红书运营」。
6. **分享模板污染**：分类前移除“复制这段文字”“打开小红书看笔记”等分享动作；`rawShareText` 原文保留，同时保存本地 `normalizedContentText`。
7. **专辑分组**：自动专辑只接受同一内容主题和二级主题、至少 2 条、非低置信度的收藏；仅共享用途、模板词或宽泛平台词不会自动跨主题成组，宁可暂不成组。
8. **行动卡**：已有的目标、原因、1—3 步、产出和完成标准保持可编辑；新增“产出 / 备注”保存入口。分类 E2E 已覆盖竞品流量行动卡。
9. **完成路径**：详情页主路径为「加入今日 → 开始行动 → 保存产出 → 标记完成」，并提供「暂时搁置」与「撤销完成」。
10. **刷新持久化**：新增 UI E2E 验证产出、完成状态在刷新后仍保留。
11. **Mock 提示**：导入页面文案明确为“当前为本地规则模式，分类与行动建议为基础版，可人工修改；不会自动上传收藏内容”。
12. **桌面与手机**：桌面详情页已覆盖；移动端既有“开始行动”主按钮保持可见。最终需由用户在真实设备上复验。
13. **测试结果**：`pnpm typecheck` 通过；扩展脚本校验通过；受影响 E2E 10/10 通过；`git diff --check` 通过。`pnpm check` 已按要求运行两次，但在本地 2 分钟和 5 分钟执行窗口均未返回，因此不将其标记为通过。

## 用户复验重点

请用同样的 8 条真实语义样本复验：打开首页后手动进入收藏页、扫描 10 或 20 条、确认诊断中的候选 / 有效 / 过滤数量；再检查分类、专辑是否拒绝跨主题聚合，以及任选一条完成“加入今日 → 开始 → 保存产出 → 标记完成 → 刷新”。
