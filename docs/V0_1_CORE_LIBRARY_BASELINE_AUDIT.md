## 一、Phase 1 范围与方法

本轮只做五件事：审计扫描、分类、专辑、搜索和原帖能力；建立 100/20/30/20 四类验收集；运行当前实现得出基线；计算与 V0.1 门槛的差距；列出 Phase 2–5 的最小任务。不修改产品实现、分类/搜索规则、IndexedDB、migration、Extension 0.2.4、行动卡、App、DeepSeek 或任何 Production 能力。

证据分为三档：

1. **真实复验**：用户在真实小红书页面执行并留下可复核数量/结果。本仓库没有 20/100/200 的完整记录。
2. **合成验收**：本轮合成/脱敏数据直接调用当前实现计分，可作为分类、专辑、搜索的可重复基线。
3. **结构回归**：E2E、DOM fixture、静态实现证明入口或结构存在，但不能替代真实页面成功率。

本轮运行结果：

- 扩展静态校验与 DOM fixture：PASS；
- Production/Preview 扩展 profile 校验：PASS；
- 现有分类、导入/专辑、搜索、原帖解析相关 E2E：11/11 PASS；
- Phase 1 合成基线执行：1/1 PASS（执行器通过只说明完成计分，不代表质量门通过）；
- 新验收结果：分类一级 88%、二级 72%；专辑相关精度 70%；自然语言搜索 Top-5 33.33%；真实原帖打开率无合格分母。

## 二、当前扫描基线

### 已存在

- Manifest V3 扩展只在用户主动点击后读取当前已加载的可见 DOM，不模拟登录、不调用隐藏接口、不绕过验证码；
- 能识别收藏页、受限/验证码状态、提取为空与真实非收藏页；
- 自动滚动、暂停、继续、重试、断点状态和勾选状态写入扩展本地存储；
- 导入前预览、全选/取消、过滤、缺标题/缺链接/重复提示；
- 候选、有效、过滤原因、重复、缺链接、待导入数量有结构化字段或 UI；
- Web 导入管线按 `sourceUrl`，无 URL 时按标题去重；重复导入不会再次创建相同 SavedItem；
- 当前生产扩展 manifest 为 `0.2.3`，仓库另有已构建 Preview `0.2.4` 产物；本轮均未修改。

## 八、与 V0.1 目标的关键差距

1. 扫描器上限与目标直接冲突：当前最多 20，目标要 50/100/200。
2. 没有 20/100/200 的真实扫描计数和误差记录，扫描稳定性不能量化。
3. 数据对象尚未收敛到目标 SavedItem/Album/AlbumMembership/SearchDocument 字段。
4. 分类一级已过，但二级和跨领域误分未过；人工修正 authority 未被重整流程显式保护。
5. 专辑按类目键聚类，缺少具体问题一致性门，反例误组与泛化标题严重。
6. 自然语言搜索 Top-5 只有 33.33%，与上线门差 51.67 个百分点。
7. 原帖缺 `sourceId`、具体路径校验、失效提示和用户修复；真实打开成功率未知。
8. 合并/拆分/批量移动专辑尚无完整实现证据。

## 九、Phase 2–5 最小修改清单

以下只是后续阶段最小任务定义，本轮没有执行。

### Phase 2：扫描、原帖和数据质量

1. 把数量选择扩到 10/20/50/100/200，移除 scanner 单批 `.slice(0, 20)` 和 20 条 clamp，同时保留“尽可能扫描全部”为 Beta。
2. 用同一状态机验证暂停、继续、关闭扩展后恢复、重试和 200 条连续扫描；记录候选/有效/重复/缺链/过滤原因及误差。
3. 冻结原始字段不可变策略，建立稳定 `normalizedContent`，原始标题/正文/URL 不被覆盖。
4. 提取并保存 `sourceId`，校验具体原帖路径，拒绝 profile/非具体路径；补失效提示与用户修复入口。
5. 使用本地、不提交的真实数据分别跑 20/100/200 和 20 条原帖，第二次导入新增必须为 0。

### Phase 3：分类与人工纠正

1. 先冻结 V0.1 一级/二级类目契约及旧类目映射，不先接新模型。
2. 修正本 100 条中的二级和跨领域失败；低置信度可进入“暂不明确”。
3. 将用户修正作为显式最高 authority，刷新、重新整理和算法升级均不覆盖；提供主动恢复系统建议。
4. 只有一级 ≥85%、二级 ≥75%、跨领域 ≤8% 后停止，不用追加同分布样本稀释错误。

### Phase 4：专辑

1. 在成组前增加具体问题一致性、成员直接相关性、宽类目拒绝和低置信度拒绝门。
2. 生成具体标题，禁止“内容、素材、生活、AI、其他”等泛名，也禁止“以后查阅”主导主题名。
3. 完成新建、改名、归档、移入/移出、多选移动、合并、拆分、自动转手动和拒绝记忆。
4. 用固定 20 组验收至相关准确率 ≥85%、跨主题 ≤10%、重复 ≤5%。

### Phase 5：搜索

1. 明确由 SavedItem、用户备注和专辑名派生的 `SearchDocument`，不建第二真相源。
2. 补中文短语与 2/3-gram、同义词/`semanticAliases`、拼音/首字母、编辑距离和字段权重。
3. 限制宽类目语义加分，确保排名理由能解释“为什么是这条”。
4. 固定本 30 条查询复验至 Top-5 ≥85%、标题 Top-1 ≥95%、无关 Top-3 ≤10%；仍不达标时才评估可替换语义 Provider。
