# V0.1 “忘记标题”搜索验收集与基线

`V0_1_SEARCH_STATUS: FAIL_BLOCKING`

## 口径

- 数据版本：`2026-07-29.phase1`
- 数量：30 条自然语言查询与 30 条合成目标收藏；全部为合成数据。
- 每条查询只指定 1 个目标 ID；Top-5 中出现目标即命中。
- 精确标题 Top-1 使用同一 30 条语料，直接以完整标题查询。
- 明显无关 Top-3 比例按“返回的 Top-3 槽位中非目标结果数 / 实际返回槽位数”计算。当前 30 次查询只返回 42 个 Top-3 槽位，其中 33 个不是目标，故为 `33/42=78.57%`；空结果不计作无关，但已在 Top-5 召回中计为失败。
- 当前搜索对标题、关键词、实体、分类、备注、摘要/分享文本、行动卡和专辑加权，并展示命中原因；没有中文 2/3-gram、拼音/首字母、编辑距离、系统语义别名或稳定同义词扩展。
- 基线直接调用 `searchSavedItems`；不接网络、不接模型、不改生产代码。

## 当前索引覆盖审计

| V0.1 要求字段/能力 | 当前状态 | 证据判断 |
| --- | --- | --- |
| 原始标题 | 部分 | `title/rawTitle/displayTitle/cleanedTitle` 参与，但字段仍并存 |
| 清洗正文 | 部分 | `normalizedContentText` 存在，但搜索主要依赖 `rawShareText/searchableText`，没有明确只读派生索引 |
| 一句摘要 | 有 | `summary` 参与 |
| 一级/二级分类 | 有 | 当前/兼容字段均参与 |
| 收藏意图 | 有 | 当前/兼容字段均参与 |
| 关键词、实体 | 有 | 分别加权并显示命中原因 |
| 用户备注 | 有 | 参与并有原因 |
| 专辑名称 | 有 | 标题、描述、关键词等参与 |
| 作者 | 缺 | `SavedItem` 未稳定保存作者，搜索也未直接索引 |
| `semanticAliases` | 缺 | 类型和索引均无稳定字段 |
| 中文 2/3-gram | 缺 | 未实现 |
| 拼音/首字母容错 | 缺 | 未实现 |
| 编辑距离/模糊匹配 | 缺 | 未实现 |
| 可解释结果 | 有但不完整 | 有标题/关键词/实体/分类/备注/分享信息/行动卡/专辑原因；宽泛语义加分原因不说明为何该条优于同类 |

## Blocking 与下一阶段边界

Phase 1 不调搜索权重。Phase 5 的最小顺序应是：先冻结 `SearchDocument` 的派生字段与权重口径，补中文短语及 2/3-gram、同义词/`semanticAliases`、拼音和编辑距离，再用本 30 条集合复验；只有本地混合搜索仍低于门槛时才评估向量检索或服务器语义查询。不得先接新模型或搭向量数据库。
